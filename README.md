# 🌲 The Forest Finder: Random Forest Explorer

An interactive Machine Learning simulation designed to teach **Ensemble Learning** and **Decision Trees**. You play as a Park Ranger trying to predict whether a rare animal will visit a specific trail today based on weather and time conditions. Instead of relying on a single model, this game demonstrates how aggregating the "wisdom of the crowd" creates a highly resilient predictive network[span_0](start_span)[span_0](end_span).

## 🎓 Learning Objectives

This project focuses on teaching:
* **Ensemble Learning:** The methodology of combining multiple machine learning models to generate a single, superior predictive output[span_1](start_span)[span_1](end_span).
* **Decision Trees:** Rule-based classifiers that split data into branches to arrive at conclusions[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).
* **Bootstrapping (Bagging):** The practice of training individual trees on randomized subsets of features or data to ensure diversity[span_4](start_span)[span_4](end_span).
* **Majority Voting (Aggregation):** The democratic process where an ensemble tallies predictions from all models and outputs the most popular choice[span_5](start_span)[span_5](end_span).

---

## ✨ Features

* **Ranger-Themed Scenario:** Translates core data structures into an intuitive wildlife monitoring mission.
* **Simulated Feature Biases:** Intentionally introduces minor biases into individual trees to show how errors cancel out across an ensemble[span_6](start_span)[span_6](end_span).
* **Tie-Prevention Warning:** Includes programmatic guidance to help users understand why odd numbers of estimators are preferred for majority voting.
* **Ground Truth Evaluation:** Mechanically compares the aggregate prediction against hidden logic representing actual animal preferences.
